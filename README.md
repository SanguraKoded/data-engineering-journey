# Data Engineering Journey

A practical learning repository documenting my journey towards becoming a data engineer through hands-on projects, exercises and technical documentation.

- SQL
- Pandas
- Git and GitHub
- Apache Spark
- Docker
- PostgreSQL

## How to Run

Clone the repository:

```bash
git clone https://github.com/SanguraKoded/data-engineering-journey.git
cd data-engineering-journey
```

Install dependencies when required:

```bash
python -m pip install pandas pytest
```
